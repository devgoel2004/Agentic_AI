Artificial Intelligence is transforming modern technology. 
Companies use AI to automate repetitive tasks and improve decision making.

Machine Learning is a subset of Artificial Intelligence.
Machine Learning allows computers to learn patterns from data.
It is widely used in recommendation systems and fraud detection.

Deep Learning is a subset of Machine Learning.
Deep Learning uses neural networks with multiple layers.
It powers modern applications such as image recognition and language models.

Vector databases store high-dimensional embeddings.
They help applications perform efficient similarity searches.
Vector databases are an important component of modern RAG systems.
